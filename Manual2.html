Overview

The course registration system allows students to enroll in courses, view schedules, and manage registrations. The home page is the base of operations for the site. There are six tabs: Enroll Student, Add Instructor, Register Course, Add Course, Drop Course, and the Manuals.

Web Pages Summary

  • Home Page: Location of all links relevant to registering for classes at Marietta College
  • Enroll Student Page: Where students can enroll and verify eligibility.
  • Add Instructor: Choose and view instructors and their teaching schedules.
  • Add Course: Search for available courses based on schedule and timing.
  • Register Course: Where a student registers for classes.
  • Drop Course: Where a student requests to drop a class.

Detailed Page Descriptions

The registration system includes six main pages, each containing labeled fields for user input. The forms collect data such as student/instructor details, course attributes, and registration requests.

View Courses Page

This page allows users to view a list of courses based on a selected student or instructor. After choosing an option, the relevant list will appear. Upon selection, course information is displayed in a table, including name, time, days, credits, and instructor. If no results are found, a message will be shown.

View Students Page

This page displays students registered in a specific course or in all courses for a selected semester. After choosing how to view, select from a list of available courses or semesters. A table shows each student's name, major, year, email, and course details if applicable. Missing data triggers a message.

Technical Overview

The system is built using HTML, CSS, JavaScript for frontend, and PHP/MySQL for backend. The current system is a series of HTML pages that will be modified to include database interaction.

Web Pages Summary

  • index.html: Home page with navigation and introductory content.
  • enrollment.html: Student enrollment form.
  • instructor.html: Add instructor information.
  • addcourse.html: Add new course details.
  • registercourse.html: Register a student for a course.
  • dropcourse.html: Drop a student from a course.

Page Functions

Each page includes input forms with clearly labeled fields. JavaScript is used for client-side validation. PHP scripts will process form data and interact with the database. Form structure is consistent across all pages.

Database Tables

  • Students:
    • student_id (int, PK, auto-increment)
    • firstname (nvarchar, NOT NULL)
    • lastname (nvarchar, NOT NULL)
    • rank (nvarchar, NOT NULL)
    • dept (nvarchar, NOT NULL)
    • major (nvarchar, NOT NULL)
  • Instructors:
    • instructor_id (int, PK, auto-increment)
    • first_name (nvarchar, NOT NULL)
    • last_name (nvarchar, NOT NULL)
    • email (nvarchar, NOT NULL)
    • department (nvarchar, NOT NULL)
    • rank (nvarchar, NOT NULL)
  • Courses:
    • course_prefix (nvarchar, NOT NULL)
    • course_number (nvarchar, NOT NULL)
    • course_section (nvarchar, NOT NULL)
    • course_name (nvarchar, NOT NULL)
    • semester (nvarchar, NOT NULL)
    • room (nvarchar, NOT NULL)
    • days (nvarchar, NOT NULL)
    • time (nvarchar, NOT NULL)
    • credit_hours (int, NOT NULL)
    • instructor_first_name (nvarchar, NOT NULL)
    • instructor_last_name (nvarchar, NOT NULL)
    • enrollment_cap (int, NOT NULL)
  • Registration:
    • first_name (nvarchar, NOT NULL)
    • last_name (nvarchar, NOT NULL)
    • semester (int, FK)
    • course_prefix (int, FK)
    • course_number (int, FK)
    • course_section (int, FK)

New Page Functions

view_courses.php

User selects to view by student or instructor.
Fetch names via: 

SELECT student_id, CONCAT(first_name, ' ', last_name) FROM Students;
SELECT instructor_id, CONCAT(first_name, ' ', last_name) FROM Instructors;
After selection, show registered/taught courses: 
-- For student:
SELECT C.course_prefix, C.course_number, C.course_name, C.days, C.time, C.room, C.credit_hours, 
       I.first_name, I.last_name
FROM Courses C
JOIN Registration R ON C.course_id = R.course_id
JOIN Instructors I ON C.instructor_id = I.instructor_id
WHERE R.student_id = ?;

-- For instructor:
SELECT * FROM Courses WHERE instructor_id = ?;
JavaScript handles which list to show.
